Highlights

This is a Sabbat Black Hand {{ rush }} deck built on the group 4–5 Banu Haqim {{ assamite_legacy }} crypt led by {{ karif }} and {{ izhim }}, bringing universal superior Quietus {{ QUI }} and near-universal superior Celerity {{ CEL }}.

The rush engine runs on contracts: {{ hand_contract }}, {{ priority_contract }} and {{ shakar_the_hunt }} enter play as trifles and provide stealthy rushes without clogging the action slots. {{ reunion_kamut }} and {{ villein }} bring the heavy crypt out, while {{ karif }}, {{ tattoo_signal }} and {{ monster }} supply extra actions.

Combat is a dedicated Quietus {{ QUI }} and Celerity {{ CEL }} dismantling kit: {{ sanguine_entrapment }} shuts down {{ sce }} or dodges, {{ dam_the_hearts_river }} and {{ thin_blood }} strip blood at close range, and {{ pursuit }} plus {{ side_strike }} stack additional strikes. {{ taste_of_vitae }} and {{ provision_of_the_silsila }} refuel after each takedown.

Once the prey's board is thinned, {{ haqims_law_retribution }} turns surplus combat cards into bleed alongside {{ loss }} and {{ fame }}. Bleed defense relies on {{ black_sunrise }}, {{ truth_in_ink }} and {{ archon_investigation }}.

Tips & Tricks

{{ haqims_law_retribution }} solves the classic rush hand-jam problem: combat cards drawn after the prey's minions are in torpor convert straight into {{ lunge }} bleed alongside {{ loss }}.

Put {{ priority_contract }} on the prey's easiest target first to trigger both pool {{ bloat }} and a {{ provision_of_the_silsila }} blood refill. Against decks with both dodge and {{ sce }} (such as Protean {{ PRO }} walls), pick the level of {{ sanguine_entrapment }} carefully since it only blocks one per round.

With no {{ bounce }} in the deck, spend an early {{ hand_contract }} backward if the predator bleeds past {{ truth_in_ink }}, or hold {{ black_sunrise }} to deter naked bleeds.

Variants

{{ jorge_s_deck }} drops {{ reunion_kamut }}, {{ tattoo_signal }} and {{ truth_in_ink }} for heavier {{ hand_contract }} (10), {{ taste_of_death }} and {{ quickness }}, adding {{ dragonbound }} for extra finishing damage.

{{ bart_s_deck }} pivots the same Black Hand Banu Haqim {{ assamite_legacy }} core into stealth-bleed and {{ bloat }}, cutting the combat kit for 12 {{ reunion_kamut }}, 6 {{ ashur_tablets }} and an Obfuscate {{ OBF }} stealth suite.
