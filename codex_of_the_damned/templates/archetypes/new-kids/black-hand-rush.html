Highlights

This is a Sabbat Black Hand {{ rush }} deck built on the group 4–5 Banu Haqim {{ assamite_legacy }} crypt. {{ karif }} stars at the top, backed by {{ izhim }}, {{ nizzam }}, {{ joe_boot_hill }}, {{ djuhah }} and {{ reza_fatir }}, giving the whole crypt superior Quietus {{ QUI }} and near-universal superior Celerity {{ CEL }}.

The rush engine runs on contracts: {{ hand_contract }}, {{ priority_contract }} and {{ shakar_the_hunt }} all enter play as trifles and hand out stealthy rushes without crowding the action slots. {{ reunion_kamut }} accelerates the heavy crypt into play alongside {{ villein }}, while {{ karif }}'s unlock ability, {{ tattoo_signal }} on the Seraphs and {{ monster }} keep the killers active both offensively and defensively.

Combat is a dedicated Quietus {{ QUI }} and Celerity {{ CEL }} dismantling kit. {{ sanguine_entrapment }} shuts down either {{ sce }} or dodges before range, {{ dam_the_hearts_river }} amps every strike while taxing opposing strikes in blood, {{ thin_blood }} strips blood directly at close range, and {{ pursuit }} plus {{ side_strike }} pile on additional strikes. {{ taste_of_vitae }} and {{ provision_of_the_silsila }} refuel after each takedown, while {{ sideslip }} absorbs return fire, {{ fast_hands }} answers weapons and {{ taste_of_death }} punishes long-range foes.

Once the prey's board is thinned, {{ haqims_law_retribution }} turns surplus combat cards into extra bleed, backed by {{ loss }}, {{ fame }}, {{ priority_contract }}'s pool {{ bloat }} and {{ enkil_cog }} on {{ karif }}. Bleed defense relies on {{ black_sunrise }} blocks, {{ truth_in_ink }} reduction and {{ archon_investigation }} deterrence, with {{ delaying_tactics }} for key votes.

Tips & Tricks

{{ haqims_law_retribution }} is what solves the classic rush hand-jam problem: combat cards drawn after the prey's minions are already in torpor are no longer dead weight, turning directly into {{ lunge }} bleed on top of {{ karif }}'s natural bonus and {{ loss }}.

Put {{ priority_contract }} on the prey's easiest or highest-value target first: clearing it fuels both pool {{ bloat }} and a full blood refill via {{ provision_of_the_silsila }} without spending an action to hunt. Against decks running both dodge and {{ sce }} (such as Protean {{ PRO }} walls), pick the level of {{ sanguine_entrapment }} carefully, since it locks out only one of the two per round.

With no {{ bounce }} in the library, {{ truth_in_ink }} and {{ archon_investigation }} only buy time against a heavy bleed predator — spend an early {{ hand_contract }} backward if the predator is untouchable on stealth, or hold {{ black_sunrise }} on {{ izhim }} or {{ karif }} to deter naked bleeds.

Variants

{{ jorge_s_deck }} is a slightly leaner, more aggressive take on the same contract-rush frame: it drops {{ izhim }}, {{ reunion_kamut }}, {{ tattoo_signal }} and {{ truth_in_ink }} to push deeper on {{ hand_contract }} (10), {{ taste_of_death }} (4) and {{ quickness }} (4), adding {{ focus_the_blood }} for blood economy and {{ dragonbound }} for extra finishing damage.

{{ bart_s_deck }} pivots the same Black Hand Banu Haqim {{ assamite_legacy }} core into a slower stealth-bleed and {{ bloat }} build: it cuts the close-range combat kit for 12 {{ reunion_kamut }}, 4 {{ recruitment_exercise }}, 6 {{ ashur_tablets }} and an Obfuscate {{ OBF }} stealth suite ({{ swallowed_by_the_night }}, {{ lost_in_crowds }}), using {{ haqims_law_retribution }} and {{ loss }} as the main ousting engine.
