Highlights

This is a Sabbat Path of Death and the Soul {{ death }} ally {{ toolbox }} built on the group 6 Oblivion {{ OBL }} crypt across Hecata {{ hecata }}, Lasombra {{ lasombra }} and Tremere {{ tremere }}. Rather than centering on one star, the crypt spreads across twelve Path vampires whose abilities reinforce ally recruiting, survival, stealth and unlocking.

The engine floods the board with undead allies — {{ gravebound_drone }} as the durable bleed and damage-soaking backbone, backed by {{ freakish_conglomeration }}, {{ aggressive_corpse }} and {{ rotting_behemoth }} for rush pressure, plus {{ fiorella }} and {{ heartrender }} as utility wraiths. {{ paths_in_two_worlds }} recruits them at stealth and unlocks the recruiter, while {{ charisma }}, {{ the_line }}, {{ perfectionist }} and {{ burial_site_hunting_ground }} absorb the heavy blood cost.

Pool damage stacks quickly from multiple angles. {{ gifts_from_hereafter }} adds bleed and unlocks the acting ally for a second action, {{ cursed_abattoir }} converts fallen zombies into extra bleed, and {{ shroud_of_decay }} supplies a bounce-proof {{ lunge }} finish. In combat, {{ dance_of_the_dead }} and {{ target_vitals }} give the rush zombies real teeth, while {{ graverobbing }} capitalizes on any opposing vampire they send to torpor.

Defense combines an ally wall with standard Oblivion {{ OBL }} and Dominate {{ DOM }} / Auspex {{ AUS }} tools: {{ the_unmasking }}, {{ fbi_special_affairs_division }}, {{ krcg_news_radio }} and {{ shadow_sentinel }} turn locked zombies into dangerous interceptors, {{ deflection }}, {{ redirection }}, {{ telepathic_misdirection }} and {{ my_enemys_enemy }} handle {{ bounce }}, and {{ pass_through_shadow }} gives the vampires clean {{ sce }} with lingering stealth.

Tips & Tricks

Blood is the deck's tightest resource: recruiting undead burns through vampire blood quickly, so establish {{ perfectionist }}, {{ charisma }} or {{ the_line }} early and use {{ putrescent_sustenance }} to convert spent allies in the ash heap back into vampire blood or fresh zombie life.

Protect the stealth-recruiting window with {{ paths_in_two_worlds }}, {{ where_the_veil_thins }}, {{ stygian_shroud }}, {{ shadow_cloak }} and {{ shadow_cast }}. Because {{ gifts_from_hereafter }} requires an unlocked Path vampire, sequence ally actions earlier in the minion phase before locking the last vampire on {{ shroud_of_decay }} or {{ graverobbing }}.

{{ aggressive_corpse }} and {{ rotting_behemoth }} require a Hecata {{ hecata }} recruiter — plan around them only when {{ ashur_uballit }}, {{ huldu }} or another Hecata {{ hecata }} is in play, and save {{ direct_intervention }} for key opposing minion cards on opponents' turns. {{ giants_blood }} and {{ blood_doll }} keep the larger vampires topped up through the mid-game.

Variants

Early builds split cleanly along which undead allies carry the deck. {{ aitor_s_deck }} trims the crypt down to 3 copies each of {{ frau_schadel }} and {{ sakura }} (with {{ parijat }} and {{ tommaso_sforza }} supporting from Hecata {{ hecata }}) and runs 10 {{ freakish_conglomeration }} alongside 8 {{ spectral_servitor }} and 6 {{ shroud_of_decay }} for a faster rush-and-bleed curve.

{{ jennifer_s_deck }} drops the zombies completely for 16 {{ spectral_servitor }}, 9 {{ gifts_from_hereafter }} and 8 {{ shroud_of_decay }}, running a lower-capacity crypt around pure wraith swarm bleed.
