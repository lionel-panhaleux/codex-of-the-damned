Highlights

This is a Sabbat Path of Death and the Soul {{ death }} ally {{ toolbox }} built on the group 6 Oblivion {{ OBL }} crypt across Hecata {{ hecata }}, Lasombra {{ lasombra }} and Tremere {{ tremere }}. Rather than starring one vampire, the crypt spreads across twelve Path minions supporting ally recruiting, survival and unlocking.

The engine floods the board with undead allies — {{ gravebound_drone }} as the durable backbone, {{ freakish_conglomeration }}, {{ aggressive_corpse }} and {{ rotting_behemoth }} for rush pressure, plus {{ fiorella }} and {{ heartrender }} for utility. {{ paths_in_two_worlds }} recruits them at stealth and unlocks the recruiter, while {{ charisma }}, {{ the_line }} and {{ perfectionist }} absorb the blood cost.

Pool damage stacks from several angles: {{ gifts_from_hereafter }} pumps bleed and unlocks the ally, {{ cursed_abattoir }} turns fallen zombies into extra bleed, and {{ shroud_of_decay }} provides a bounce-proof {{ lunge }}. {{ dance_of_the_dead }} and {{ target_vitals }} back up the rush zombies, with {{ graverobbing }} capitalizing on torporized vampires.

Defense pairs an ally wall — {{ the_unmasking }}, {{ fbi_special_affairs_division }} and {{ shadow_sentinel }} — with {{ deflection }} and {{ telepathic_misdirection }} for {{ bounce }}, plus {{ pass_through_shadow }} for vampire {{ sce }}.

Tips & Tricks

Blood is the tightest resource: establish {{ perfectionist }}, {{ charisma }} or {{ the_line }} early and use {{ putrescent_sustenance }} to turn ash-heap allies back into vampire blood or fresh zombie life.

Because {{ gifts_from_hereafter }} requires an unlocked Path vampire, run ally actions before locking the last vampire on {{ shroud_of_decay }} or {{ graverobbing }}. Keep in mind that {{ aggressive_corpse }} and {{ rotting_behemoth }} require a Hecata {{ hecata }} recruiter such as {{ ashur_uballit }} or {{ huldu }}.

Variants

Early builds split along which undead carry the deck. {{ aitor_s_deck }} trims the crypt around {{ frau_schadel }} and {{ sakura }} and runs 10 {{ freakish_conglomeration }} alongside 8 {{ spectral_servitor }} and 6 {{ shroud_of_decay }} for a faster rush-and-bleed curve.

{{ jennifer_s_deck }} drops the zombies altogether for 16 {{ spectral_servitor }}, 9 {{ gifts_from_hereafter }} and 8 {{ shroud_of_decay }}, pivoting to a lower-capacity wraith swarm.
