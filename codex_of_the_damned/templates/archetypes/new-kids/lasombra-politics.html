Highlights

This is a vote deck on the group 6 Camarilla Lasombra {{ lasombra }} crypt: almost every vampire is titled and brings Dominate {{ DOM }} and Oblivion {{ OBL }}, backed by {{ power_structure }}. The early game is pure setup — in the author's words, transfer, {{ govern_the_unaligned }}, {{ villein }}, almost never bleed — before launching referendums once two or three titles are out.

{{ kine_resources_contested }}, {{ camarilla_s_iron_fist }} and {{ parity_shift }} drive the pool damage, backed by {{ ominous_chorus }} and {{ lasombra_justicar }} for vote lock while {{ amici_noctis }} refills blood and pool. Oblivion {{ OBL }} stealth ({{ where_the_veil_thins }}, {{ shadow_cast }}, {{ shadow_cloak }}, {{ stygian_shroud }}) pushes votes through, and superior {{ pass_through_shadow }} banks a +1 stealth after escaping combat.

Built to weather heavy bleed tables, the deck leans on all-crypt {{ deflection }} and heavy recovery from {{ villein }}, {{ giant_s_blood }} and {{ amici_noctis }}.

Tips & Tricks

{{ amici_noctis }} rewards winning referendums by a wide margin. Keep an unlocked title up so {{ ominous_chorus }} can swing other players' votes too, and use {{ yewon_ong }} to turn surplus {{ obl }} cards like {{ shadow_cast }} into late-game votes.

Hold superior {{ stygian_shroud }} for committed blockers, cycle or hold superior {{ shadow_cloak }} as anti-rush tech, and save superior {{ shroud_of_decay }} for an unbounceable finish. {{ spectral_servitor }} wraiths act as cannon fodder against rushes or extra 1-bleeds, with {{ shadow_sentinel }} for surprise blocks.

Variants

{{ jorge_garcia_s_deck }} leans into control: no wraiths or {{ shroud_of_decay }}, replaced by 10 {{ deflection }}, 4 {{ second_tradition_domain }}, 4 {{ freak_drive }} and extra {{ amici_noctis }} and {{ pass_through_shadow }}.

{{ ivan_marin_rivas_deck }} pulls the other way with 10 {{ spectral_servitor }}, 6 {{ parity_shift }} and a Dominate {{ DOM }} bleed splash ({{ conditioning }}, {{ bonding }}, {{ foreshadowing_destruction }}).
