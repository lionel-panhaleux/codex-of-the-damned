Highlights

This is a group 6 Lasombra {{ lasombra }} {{ rush }} deck anchored by Camarilla Princes {{ dafina }}, {{ yewon_ong }} and {{ maria_del_toro }}, backed by {{ kamaluddin }} plus Sabbat splashes {{ damian }} and {{ lyyli }} for extra inferior Fortitude {{ for }}.

{{ umbrous_clutch }} delivers stealthy rushes with an optional maneuver (backed by {{ dafina }}'s built-in rush), feeding into a classic Potence {{ POT }} grapple package: {{ torn_signpost }}, {{ immortal_grapple }} against {{ sce }} and dodges, {{ shadow_shift }} for maneuvers and extra strikes, {{ disarm }} and {{ taste_of_vitae }}. {{ heroic_might }} and {{ preternatural_strength }} add permanent strength, while {{ hidden_strength }} absorbs return fire.

Unlike older Potence {{ POT }} rush decks that struggle to oust, {{ dead_pool }} turns combat takedowns into big bleeds or extra votes on {{ parity_shift }}, backed by {{ govern_the_unaligned }}, {{ fame }} and {{ shroud_of_decay }}.

With Princes and superior Dominate {{ DOM }}, defense stays tight: {{ second_tradition_domain }} threatens ambush blocks into grapple combat, {{ deflection }} and {{ on_the_qui_vive }} cover {{ bounce }}, and {{ freak_drive }} lets the Fortitude {{ for }} vampires rush, unlock and bleed or sit back on defense.

Tips & Tricks

Land {{ dead_pool }} before going on a spree: counters only accrue once it is in play, and two or three turn a routine {{ govern_the_unaligned }} into a lethal {{ lunge }} or lock in a late {{ parity_shift }}.

Use {{ umbrous_clutch }} and {{ shadow_shift }} to pull ranged-combat decks into close range for {{ immortal_grapple }} and {{ disarm }}. Put {{ heroic_might }} on the main rusher and {{ preternatural_strength }} on a second vampire so {{ torn_signpost }} never clashes with it.

Leave a Prince unlocked or holding {{ second_tradition_domain }} against setup-heavy predators — one surprise block into {{ immortal_grapple }} often stalls their turn without spending an action.
