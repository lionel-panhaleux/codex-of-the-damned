Highlights

This is a group 6 Lasombra {{ lasombra }} {{ rush }} deck anchored by the Camarilla Princes {{ dafina }}, {{ yewon_ong }} and {{ maria_del_toro }}, backed by {{ kamaluddin }} and Sabbat splashes {{ damian }} and {{ lyyli }} for extra inferior Fortitude {{ for }}. Two-thirds of the crypt carries Dominate {{ DOM }}, Oblivion {{ OBL }} and Potence {{ POT }} at superior, while two-thirds carries Fortitude {{ for }}.

{{ umbrous_clutch }} delivers stealthy rushes with an optional maneuver (backed by {{ dafina }}'s built-in rush), feeding straight into a classic Potence {{ POT }} grapple package: {{ torn_signpost }}, {{ immortal_grapple }} against {{ sce }} and dodges, {{ shadow_shift }} for maneuvers and additional strikes, {{ disarm }} to cripple survivors and {{ taste_of_vitae }} to refill. {{ heroic_might }} and {{ preternatural_strength }} stack permanent strength for long tables, while {{ hidden_strength }} keeps the Fortitude {{ for }} vampires standing through return fire.

Unlike older Potence {{ POT }} rush shells that struggle to convert combats into ousts, the Lasombra {{ lasombra }} have a clean finishing engine: {{ dead_pool }} banks counters whenever a combat removes a vampire and spends them for big bleeds or extra votes on {{ parity_shift }}, backed by {{ govern_the_unaligned }}, {{ fame }} and {{ shroud_of_decay }}.

Because the crypt is packed with Princes and superior Dominate {{ DOM }}, defense stays tight while rushing: {{ second_tradition_domain }} punishes opposing actions with ambush blocks into grapple combat, {{ deflection }} and {{ on_the_qui_vive }} cover {{ bounce }}, and {{ freak_drive }} lets the Fortitude {{ for }} vampires rush, unlock and bleed or sit back on defense. {{ govern_the_unaligned }}, {{ villein }}, {{ papillon }}, {{ powerbase_montreal }}, {{ giants_blood }} and {{ wider_view }} drive the early ramp and {{ bloat }}.

Tips & Tricks

Land {{ dead_pool }} before going on a spree — counters only accrue once it is in play, and storing even two or three turns a routine {{ govern_the_unaligned }} bleed into a lethal {{ lunge }} or guarantees a late {{ parity_shift }} passes.

Use {{ umbrous_clutch }} and {{ shadow_shift }} to drag gun and ranged-combat decks back into close range where {{ immortal_grapple }} and {{ disarm }} lock them out. Play {{ heroic_might }} on the primary rusher and save {{ preternatural_strength }} for a second vampire so {{ torn_signpost }} never clashes with it.

Leave a Prince unlocked or holding {{ second_tradition_domain }} whenever the predator threatens setup actions — a single surprise block into {{ immortal_grapple }} often halts the predator's whole game plan without spending an action on one's own turn.

Variants

This list leans into inferior Fortitude {{ for }} with 6 {{ freak_drive }} and 6 {{ hidden_strength }} to support multi-acting and damage prevention. Other winning builds cut {{ freak_drive }} in favor of heavier combat density and {{ monster }} unlocks.
