Highlights

This is a Sabbat {{ wall }} starring {{ agnieszka }}, backed by Auspex {{ AUS }} and Protean {{ PRO }} support — chiefly {{ xipe_totec }} and {{ verrix }} — with {{ new_blood }} speeding up the crypt dig.

Defense is virtually impenetrable without ever committing to a fight. {{ eyes_of_argus }}, {{ eagles_sight }}, {{ enhanced_senses }} and {{ form_of_the_bat }} stack intercept atop permanents like {{ bowl_of_convergence }}, {{ abbot }}, {{ under_siege }} and {{ eternal_vigilance }}. Blocks end safely through {{ earth_meld }}, {{ form_of_mist }} or {{ agnieszka }}'s built-in {{ sce }}, with basic {{ charismatic_aura }} cancelling grapples or dangerous strikes.

Offense is slow, relentless attrition from {{ enkil_cog }} on {{ agnieszka }}. {{ monastery_of_shadows }}, {{ opium_den }} and {{ form_of_mist }} push her bleeds through across the table cycle, while {{ forward_momentum }} unlocks her to keep pressing or sit back on defense. {{ telepathic_misdirection }} handles {{ bounce }} and {{ delaying_tactics }} guards against votes.

Prioritize landing {{ heart_of_nizchetus }} and {{ bowl_of_convergence }} early — {{ the_british_museum }} makes equipping both fast and cheap — and stick {{ enkil_cog }} as soon as a bleed can sneak through.

Hold {{ charismatic_aura }} against Potence {{ POT }} rush decks to cancel {{ immortal_grapple }} instead of cycling it early; lean on {{ earth_meld }} and {{ agnieszka }}'s built-in {{ sce }} for routine blocks. {{ the_sargon_fragment }} recovers whichever key reaction or {{ pentex_subversion }} is needed to close the prey out.
