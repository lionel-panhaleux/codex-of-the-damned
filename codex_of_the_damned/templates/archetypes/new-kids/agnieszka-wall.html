Highlights

This is a Sabbat {{ wall }} starring {{ agnieszka }}, backed by high-capacity Auspex {{ AUS }} and Protean {{ PRO }} support — chiefly {{ xipe_totec }}, with {{ verrix }} adding Auspex {{ AUS }} and Presence {{ PRE }} — and {{ new_blood }} speeding up the crypt dig alongside {{ wider_view }}.

Defense is built to be virtually impenetrable without ever committing to a fight. {{ eyes_of_argus }}, {{ eagles_sight }}, {{ enhanced_senses }} and {{ form_of_the_bat }} supply the intercept on top of permanents like {{ bowl_of_convergence }}, {{ mr_winthrop }}, {{ abbot }}, {{ saatet_ta }}, {{ under_siege }} and {{ eternal_vigilance }}. Every block ends safely through {{ earth_meld }}, {{ form_of_mist }}, {{ charismatic_aura }} or {{ agnieszka }}'s built-in {{ sce }} — with {{ earth_meld }} unlocking her right back for the next block, and basic {{ charismatic_aura }} cancelling grapples that would shut down the {{ sce }} loop or threatening strike cards.

Offense is slow, relentless attrition from {{ enkil_cog }} on {{ agnieszka }}. With her natural bleed bonus, {{ monastery_of_shadows }}, {{ opium_den }} and {{ form_of_mist }} carry bleeds through on both her own turn and opponents' turns, while {{ forward_momentum }} unlocks her to keep pressing or sit back on defense. {{ telepathic_misdirection }} provides the {{ bounce }} when blocking is not worth the effort, and {{ delaying_tactics }} plus {{ direct_intervention }} guard against votes and key minion cards.

Blood and card flow sustain the whole machine: {{ papillon }}, {{ the_rack }} and {{ giants_blood }} refill {{ agnieszka }} for {{ villein }} and {{ bowl_of_convergence }}, {{ heart_of_nizchetus }} filters the hand each turn, and {{ monastery_of_shadows }}, {{ elder_library }}, {{ the_british_museum }} and {{ andre }} expand hand size so the wall never runs dry.

Tips & Tricks

Prioritize landing {{ heart_of_nizchetus }} and {{ bowl_of_convergence }} early — {{ the_british_museum }} makes equipping both fast and cheap — and stick {{ enkil_cog }} as soon as a bleed can sneak through. Once the equipment and stealth locations are online, the deck shifts from passive survival to multi-bleeding the prey every table cycle.

Hold {{ charismatic_aura }} against Potence {{ POT }} rush decks to cancel {{ immortal_grapple }} or dangerous strike cards instead of cycling it first; lean on {{ earth_meld }} and {{ agnieszka }}'s built-in {{ sce }} for routine blocks. Use {{ xipe_totec }} to steal opposing allies or retainers rather than trading combat cards with them.

{{ the_sargon_fragment }} and {{ pentex_subversion }} are late-game {{ lunge }} tools: recur the exact reaction, {{ enkil_cog }} or {{ pentex_subversion }} needed to strip a stubborn blocker and close the prey out.
