Highlights

This is a group 6 Lasombra {{ lasombra }} {{ stealth_and_bleed }} deck pairing Dominate {{ DOM }} ({{ govern_the_unaligned }}, {{ conditioning }}) with a steady stream of {{ spectral_servitor }} wraiths. Each vampire's first recruit unlocks them for a follow-up {{ govern_the_unaligned }}, while the Servitor plays the costless basic Oblivion {{ obl }} stealth modifiers ({{ shadow_cast }}, {{ shadow_cloak }}, {{ where_the_veil_thins }}, {{ stygian_shroud }}) to bleed alongside them.

Defense combines all-crypt {{ deflection }} {{ bounce }} with a wraith blocking screen: {{ shadow_sentinel }} wakes locked Servitors under {{ the_unmasking }}, {{ target_vitals }} gives them teeth, and {{ fbi_special_affairs_division }} deters opponents from hunting them.

Tips & Tricks

Do not pay Servitor upkeep by reflex — a recruit that unlocked its vampire and bled for 1 has already paid for itself. Keep one only when {{ the_unmasking }} is out, a {{ rush }} deck sits nearby, or next-turn pressure matters.

Spend raw stealth first and hold {{ stygian_shroud }} for committed blockers. Combat is thin — {{ pass_through_shadow }} gives vampires a small escape hatch while {{ target_vitals }} lets blocking Servitors hit back — so Auspex {{ AUS }} {{ wall }} and {{ rush }} tables are the hardest matchups.

Variants

Most lists add a few {{ shroud_of_decay }} for unbounceable reach, as in {{ alessandro_donati_s_deck }}; Lukáš Simandl's all-Govern pack is the outlier for skipping it.

{{ yuri_furtado_prange_s_deck }} leans on 6 {{ ashur_tablets }} and extra {{ parijat_the_dark_oracle }}, whereas {{ zoltán_panyik_s_deck }} trims to 8 Servitors with 5 {{ villein }} and 19 reactions for a slower, {{ toolbox }}-paced game.
