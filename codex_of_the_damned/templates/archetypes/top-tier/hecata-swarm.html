Highlights

This is a group 6 Hecata {{ hecata }} swarm bleed deck built around {{ spectral_servitor }}. Because the Servitor plays costless basic Oblivion {{ obl }} cards as a vampire, {{ shadow_cast }}, {{ shadow_cloak }}, {{ stygian_shroud }} and {{ where_the_veil_thins }} push both the wraiths and the vampires through, while {{ charisma }} makes recruiting free and {{ shroud_of_decay }} adds unbounceable reach.

{{ family_gathering }} speeds the all-Hecata {{ hecata }} crypt into play. Defense combines Auspex {{ AUS }} {{ bounce }} ({{ telepathic_misdirection }}) with a blocking swarm via {{ the_unmasking }}, {{ shadow_sentinel }} and {{ parijat }}.

Tips & Tricks

Spread recruits across different vampires since only the first recruit each turn unlocks its recruiter, leaving vampires free to bleed with {{ shroud_of_decay }} or hold {{ telepathic_misdirection }} open.

Do not pay Servitor upkeep by reflex — letting a spent wraith burn is fine business unless blockers under {{ the_unmasking }} or next-turn pressure are needed, and {{ mora }} and {{ lenelle }} can recycle burnt copies. With no combat cards and only {{ delaying_tactics }} against {{ vote }} decks, watch out for {{ anarchist_uprising }} and ally-hate tables.

Variants

Lists split along how far they lean into {{ shroud_of_decay }} over the swarm: {{ stefano_chiodi_s_deck }} trims to 6 Servitors for 12 {{ shroud_of_decay }}, {{ villein }} {{ bloat }} and 8 {{ pass_through_shadow }} (closer to classic {{ stealth_and_bleed }}), while {{ ke_carlton_s_deck }} runs 14 {{ shroud_of_decay }} and 11 {{ family_gathering }}.

{{ richard_aumann_s_deck }} replaces the wraiths with 15 {{ bone_shambler }} and {{ cappadocian_crypt }}, dropping {{ shroud_of_decay }} entirely. {{ hecata_corpse }} shares the crypt and Oblivion {{ OBL }} stealth, but pivots to {{ aggressive_corpse }} and utility allies as a {{ toolbox }}.
