Highlights

This is a vote deck on an all-titled group 6 and 7 Camarilla crypt built around {{ juliet_parr }} {{ malkavian }} and {{ modius }} {{ toreador }}. The two stars share a loop: passed referendums grow the hand through {{ juliet_parr }}, and {{ modius }} turns surplus masters from that overflow straight into extra votes.

{{ zillah_s_valley }} accelerates the expensive elders out, {{ villein }} claws the blood back, and {{ the_parthenon }} with {{ ashur_tablets }} sustains a deep {{ bloat }} engine. Ousting is pure referendum — {{ parity_shift }} as the workhorse alongside {{ kine_resources_contested }}, {{ camarilla_s_iron_fist }}, {{ anarchist_uprising }}, {{ ancilla_empowerment }}, {{ political_stranglehold }} and {{ banishment }}.

Political actions push through behind Obfuscate {{ OBF }} stealth ({{ forgotten_labyrinth }}, {{ lost_in_crowds }}, {{ camarilla_conclave }}, {{ monastery_of_shadows }}). Defense runs on Auspex {{ AUS }}: {{ eyes_of_argus }} and {{ second_tradition_domain }} for wakes and intercept, plus {{ telepathic_misdirection }} for {{ bounce }}.

Tips & Tricks

Run lean on pool early so {{ parity_shift }} stays live against the prey — pour pool into the crypt rather than sitting on it, then walk the prey down with chained referendums and finish with flat pool burn.

The heavy master base doubles as {{ modius }} {{ toreador }}'s ammunition, filtered by {{ heart_of_nizchetus }} and recycled through {{ ashur_tablets }}. Rely on superior {{ eyes_of_argus }} and {{ second_tradition_domain }} to keep locked elders active on defense after calling votes.

Variants

This list pivots away from Dominate {{ DOM }} — trading {{ govern_the_unaligned }} and {{ deflection }} for {{ modius }} {{ toreador }}, {{ zillah_s_valley }} and an Auspex {{ AUS }} defense. The classic Dominate {{ DOM }} branch keeps {{ govern_the_unaligned }}, {{ deflection }} and {{ obedience }}, taking the {{ augusto_s_deck }} in 2026 and the {{ tomasz_s_deck }} in 2025.

The older Malkarishat branch, {{ danilo_s_deck }}, splices in {{ arishat }} {{ baali }}: instead of generating extra votes like {{ modius }} {{ toreador }}, she forces opposing vampires to abstain to muscle referendums through.
