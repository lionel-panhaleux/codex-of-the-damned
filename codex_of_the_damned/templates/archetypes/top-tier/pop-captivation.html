Save {{ dia_de_los_muertos }} and {{ cryptic_rider }} for the closing lunge, and set {{ dark_influences }} out of turn beforehand so it sits ready to stop an opposing {{ direct_intervention }}.

High capacities make {{ ancient_influence }}, {{ political_stranglehold }} and {{ reins_of_power }} heavily tilted in the deck's favor — call them early while the table welcomes pool, and save {{ anarchist_uprising }} to close.
