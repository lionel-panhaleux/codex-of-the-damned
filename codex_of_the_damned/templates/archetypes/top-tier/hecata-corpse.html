Highlights

This is a group 6 Hecata {{ hecata }} {{ toolbox }} built on Oblivion {{ OBL }} and disposable allies, topped by {{ mora }} for bleed and recursion. {{ shroud_of_decay }} closes the prey out without risking {{ bounce }}, pushed through by the Oblivion {{ OBL }} stealth suite ({{ shadow_cast }}, {{ shadow_cloak }}, {{ where_the_veil_thins }} and {{ stygian_shroud }}).

{{ aggressive_corpse }} rush problem minions while {{ spectral_servitor }} unlock their recruiter and chip in at stealth. {{ family_gathering }} fuels the all-Hecata {{ hecata }} crypt, while {{ split_the_veil }} raises dead allies and {{ psychophagia }} converts them into blood.

Defense pairs Auspex {{ AUS }} ({{ telepathic_misdirection }}, {{ eyes_of_argus }}) with a blocking ally screen: {{ the_unmasking }}, {{ shadow_sentinel }} and {{ fbi_special_affairs_division }} turn every corpse into a serious deterrent.

Tips & Tricks

Do not pay {{ spectral_servitor }} upkeep by reflex: a Servitor that bled once has already paid for its blood, so letting it burn and raising it back with {{ split_the_veil }} is often better than spending pool.

Use {{ aggressive_corpse }} to clear blockers before a superior {{ shroud_of_decay }} lunge, with {{ dance_of_the_dead }} supplying maneuvers and presses and {{ tye_cooper }} finishing off torpored minions. Between {{ mora }} and {{ lenelle }}, prioritize recycling {{ shroud_of_decay }}.

The other branch drops {{ shroud_of_decay }} and ousts through rush attrition with {{ fame }} and {{ dragonbound }}, as in {{ nicola_lonardi_s_deck }} (6 {{ ashur_tablets }} and 4 {{ liquidation }}) or {{ ivan_candioli_s_deck }}, whose 23 reactions play like a corpse-powered {{ wall }}.
