Highlights

This is a single-vampire {{ wall }} starring {{ goratrix }} {{ tremere_antitribu }}, fueling an enormous Animalism {{ ANI }} and Auspex {{ AUS }} reaction pile — {{ read_the_winds }}, {{ eyes_of_argus }}, {{ cats_guidance }}, {{ eagle_s_sight }}, plus {{ telepathic_misdirection }} and {{ my_enemy_s_enemy }} {{ bounce }}.

{{ goratrix }}'s unpreventable ranged blood theft pairs with {{ carrion_crows }} and {{ murder_of_crows }} to punish every minion he blocks. Once the tower is up, it defends table drains — {{ smiling_jack_the_anarch }}, {{ army_of_rats }}, {{ constant_revolution }} (enabled by {{ anarch_convert }}) and {{ creeping_sabotage }} — while {{ ashur_tablets }} recycles the singletons.

Tips & Tricks

Fetch {{ heart_of_nizchetus }} first with {{ magic_of_the_smith }} to keep the sprawling wall flowing, then grab {{ bowl_of_convergence }}, {{ ivory_bow }}, {{ kevlar_vest }} or {{ ruins_of_ceoris }} as the table demands. {{ rutor_s_hand }} lets {{ goratrix }} fetch and still unlock to defend.

Pass {{ millicent_smith }} to the predator so every block — including cross-table {{ eagle_s_sight }} blocks — burns their vampire. Hold {{ pentex_subversion }} to contest, and lean on {{ anastasz_di_zagreb }} (with {{ animalism }}) and {{ omaya }} if {{ goratrix }} gets neutralized.
