Highlights

This is a classic Toreador {{ toreador }} Auspex {{ AUS }} / Celerity {{ CEL }} guns {{ wall }} starring {{ helena }}, whose ability to block and play Auspex {{ AUS }} reactions while locked anchors the whole defense. The deck blocks threats, shoots them into torpor at long range, and grinds the table out with {{ fame }} and {{ smiling_jack_the_anarch }}.

Intercept stacks on {{ eagles_sight }}, {{ enhanced_senses }}, {{ eyes_of_argus }}, {{ quicken_sight }}, {{ krcg_news_radio }} and {{ bowl_of_convergence }}, while unblocked bleeds get {{ bounce }} by {{ telepathic_misdirection }} and {{ my_enemys_enemy }}. Tips & Tricks

A blocking vampire with {{ sniper_rifle }} sets long range where most opponents cannot shoot back, and superior {{ blur }} turns that into 6 ranged damage; keep {{ psyche }} in hand to punish {{ sce }}. Do not block indiscriminately — the deck has little forward pressure and a finite library, so spend reactions on actions that matter.

Passing {{ millicent_smith }} to the predator turns every block — including cross-table {{ eagles_sight }} blocks — into a burn threat. Hold {{ wash }} against {{ pentex_subversion }} on {{ helena }}, and use {{ the_erciyes_fragments }} to lift extra reactions from the prey's ash heap.
