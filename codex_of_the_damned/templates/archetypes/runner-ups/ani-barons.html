Highlights

This is a {{ rush }} deck on group 6 Anarch Barons with superior Animalism {{ ANI }} across Tzimisce {{ tzimisce }}, Gangrel {{ gangrel }} and Ravnos {{ ravnos }}. {{ deep_song }} flexes between bleed and rush, while ranged combat pairs {{ carrion_crows }} and {{ aid_from_bats }} with {{ terror_frenzy }}, {{ drawing_out_the_beast }}, {{ taste_of_vitae }} and {{ ivory_bow }}.

{{ anarch_revolt }}, {{ fame }} and {{ tension_in_the_ranks }} convert table control into ousts. Defense runs on the Baron reaction suite — {{ bait_and_switch }} ({{ bounce }}), {{ organized_resistance }}, {{ deep_ecology }} — backed by {{ raven_spy }} and {{ mr_winthrop }}.

Tips & Tricks

Open combat with {{ carrion_crows }} and maneuver to long range with {{ aid_from_bats }}; use inferior {{ terror_frenzy }} to lock opponents at range or superior to tax combat cards. Lead multi-round rushes with {{ massimiliano }} or {{ adrino_manauara }}, and save {{ delaying_tactics }} for referendums aimed at {{ anarch_revolt }}.

{{ nsa_trio }} is one-sided here: the deck plays no {{ combat_ends }}, yet blocks against {{ deep_song }} bleeds cannot escape the first round of crows and bats. Mind {{ branimira }}'s 9-pool threshold before playing a large {{ villein }}.

Variants

The archetype is tightly consolidated: this list follows {{ jozef_patrnciak_s_deck }} almost card for card, only trimming a couple of {{ aid_from_bats }} for extra Baron reactions and the {{ delaying_tactics }} / {{ nsa_trio }} tech. Earlier builds like {{ giulio_de_cicco_s_deck }} ran a thicker reaction wall ({{ cats_guidance }}, {{ protection_racket }}), {{ army_of_rats }} and {{ groundfighting }}.
